# 单文档产品 PRD 模板

此模板在需求读取和访谈前完整加载。以下正文是输出骨架，方括号表示需要确认的内容，引用块为填写说明，最终 PRD 不保留这些标记或说明。

保留文档级章节及其职责；单个功能按第 5 章的四类信息组织，无界面时省略原型与界面，无业务状态变化时省略状态流转表。跨功能旅程可以用步骤表或 Mermaid 图，图与表使用相同业务术语。

信息只在一个权威位置维护：功能清单链接详情，状态变化与业务数据对象对应，功能通过编号引用非功能要求。用户故事与验收应清晰对应，便于用户选取一个独立功能作为开发输入。
