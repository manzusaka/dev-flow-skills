# Bolder：放大已有方向的表现力

先确认目标区域和不可改变的内容。阶段 3 尚未选定方向时，`bolder` 表示提出结构、材质或节奏都更大胆的候选方向；方向已经获批后，它表示在既有视觉语言内增强指定区域，不另起一套品牌。

## 诊断

- 对照同一页面的其他区域：目标是否没有用足既有字体层级、标志性元素、密度或节奏？
- 去掉文案只看结构：焦点、阅读顺序和产品特征是否仍可辨认？单纯放大字号并不能解决结构平淡。
- 识别增强的目的：强调一个关键动作、证据或内容，而非给所有元素加效果。

## 处理

1. 在阶段 3，围绕 `01-product.md` 的核心差异点和 `02-references.md` 的偏好生成真正不同的大胆候选；仍遵守明确禁忌。
2. 在阶段 4–6，先读取当前 `DESIGN.draft.md` 或 `docs/prototype/design/state.md` 指向的权威来源。只增强用户指定目标，复用已批准的字体、色彩、形状和动效。
3. 做一个明确的表现动作，再让周围内容保持安静，使重点可读。不得改写未经用户提供的新事实或产品承诺。
4. 记录新增的全局规则或局部 `Surface` 例外；按当前阶段生成受影响预览的新版本。

## 验证

目标更醒目，但其他区域、内容事实、操作和既有视觉身份保持一致；在实际画布与目标设备上检查，而不只看局部截图。
