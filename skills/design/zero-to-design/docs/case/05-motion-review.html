缓动曲线

所有动效都使用同一条自然减速曲线
ease-out（推荐）
cubic-bezier
(0.25, 1, 0.5, 1) · 自然减速，先快后慢
用于悬停、入场和按下。这是 Pulse 中唯一的缓动。
bounce（已弃用）
cubic-bezier
(0.34, 1.56, 0.64, 1) · 回弹效果，已弃用
回弹 / 弹性效果显得过时且分散注意力。Pulse 不使用。

动效规格

已写入 DESIGN.md 的正式参数
场景 时长 缓动 属性
悬停反馈 150ms cubic-bezier(0.25, 1, 0.5, 1) background, transform, border-color
按下反馈 150ms cubic-bezier(0.25, 1, 0.5, 1) transform: scale(0.97)
入场动画 350–500ms cubic-bezier(0.25, 1, 0.5, 1) transform, opacity
箭头微移 200ms cubic-bezier(0.25, 1, 0.5, 1) transform: translateX(3px)
细线绘制 800ms cubic-bezier(0.25, 1, 0.5, 1) transform: scaleX / scaleY
减弱动效 0.01ms linear 强制关闭所有动画

以上所有动效均遵循：只对 transform 和 opacity 做动画；不阻塞交互；尊重 prefers-reduced-motion。
