# Pulse 设计系统

> 版本：v1.0  
> 来源：zero-to-design workflow  
> 覆盖范围：仪表盘首页 + 动效系统  
> 状态：定稿

---

## 1. 设计灵魂

**Pulse** 是一款面向独立开发者的数据仪表盘。它的视觉风格是 **"编辑式的沉静"**：像一份排版精良的晨报，依靠细线、留白和信息密度来建立秩序，而不是堆砌卡片和装饰。它的目标是在 30 秒内缓解"我的产品今天怎么样了？"这种底层焦虑。

色彩策略：暖浅灰背景 + 深炭色文字 + 森林绿点缀。绿色代表"正常/健康"，只出现在状态和正向变化中；警告和错误使用低饱和度的暖棕/赭红，不刺眼。

字体策略：Display 使用 Source Serif 4，带来人文编辑气质；Body 使用 Manrope，保证数据的可读性；Mono 使用 JetBrains Mono，用于金额、百分比和时间戳。数字本身就是主角，无需图表。

动效策略：所有动效使用同一条自然减速缓动曲线，时长克制。不闪烁、不弹跳、不干扰。动效的职责是"确认"和"引导"，而不是"表演"。

### 2.2 字体规则

| 角色 | 字体 | 字重 | 字号 / 行高 | 用途 |
|------|------|--------|-------------------|-------|
| Display | Source Serif 4 | 600 | clamp(36px, 5vw, 56px) / 1.1 | 页面大标题、报头 |
| 章节标题 | Source Serif 4 | 600 | 22px / 1.2 | 章节标题（最近事件、快捷操作） |
| Body | Manrope | 400 | 15px / 1.6 | 正文、事件描述、导航链接 |
| Body Strong | Manrope | 500–600 | 14–15px / 1.6 | 事件标题、操作卡片标题 |
| Label | Manrope | 600 | 11px / 1.4，全大写，字间距 0.08em | 指标标签、微型标题 |
| Metric | JetBrains Mono | 600 | 32px / 1.1 | 关键数字 |
| Data | JetBrains Mono | 500 | 12–14px / 1.4 | 百分比、时间戳、日期 |

**字体加载**：通过 Google Fonts 加载 `Source Serif 4`、`Manrope` 和 `JetBrains Mono`，并使用 `font-display: swap` 避免布局偏移。

### 2.3 间距与形状

- **基础单位**：4px
- **页面最大宽度**：1200px
- **页面内边距**：32px（移动端 20px）
- **分区间距**：48px（报头上方）、32px（主内容内边距）
- **卡片内边距**：16px（操作卡片）、24px（指标单元横向）、28px（指标单元纵向）
- **圆角**：4px（徽标）、6px（按钮/状态条）、8px（图标容器）、10px（操作卡片）、50%（头像/圆点）
- **阴影**：仅用于悬停反馈：`0 4px 12px rgba(0, 0, 0, 0.05)`；不使用大面积装饰性阴影

## 3. 组件

### 3.1 顶部导航

- 高度 56px，吸顶，`--surface-card` 背景，底部 1px `--border-subtle` 分隔线。
- Logo 为 Source Serif 4 品牌字标；左侧 8px 圆点使用 `--accent`。
- 导航链接为 Manrope 500 14px，默认 `--text-secondary`，悬停变为 `--text-primary` + `--surface-hover` 背景，激活状态使用 `--bg-page` 背景。
- 用户头像为 32px 圆形，`--border-subtle` 背景，悬停变为 `--border-strong`。

### 3.2 报头（Masthead）

- 上内边距 48px，下内边距 28px。
- 左侧大标题（Display），右侧日期（Mono 14px）。
- 下方的状态徽标：`--badge-bg` 背景，圆点 + 文字，标示今日整体状态。

### 3.3 指标横栏

- 4 列网格，各列之间以 1px 竖线分隔。
- 单元格内边距：28px 24px，悬停背景 `--surface-hover`。
- 指标标签全大写，指标数值 JetBrains Mono 32px，变化指示使用箭头 + Mono 12px。
- **不允许内嵌趋势图或迷你图表**；趋势属于详情页或周报。

### 3.4 事件流

- 列表项为 3 列网格：时间 / 内容 / 标签。
- 时间使用 Mono 12px `--text-tertiary`；标题 Manrope 500 15px；详情 Manrope 400 13px `--text-secondary`。
- 标签使用徽标样式：Revenue/Product/Analytics 使用 `--badge-bg` + `--accent`，Attention 使用暖棕背景 + `--status-warn`。
- 列表项悬停时使用 `--surface-hover` 背景，8px 圆角，可点击。

### 3.5 快捷操作卡片

- 白色卡片，1px `--border-subtle` 边框，10px 圆角。
- 包含 36px 图标容器（`--badge-bg` 背景）、标题 + 描述，以及右箭头。
- 悬停时上浮 2px + 轻阴影 + 边框加深 + 箭头右移 3px。
- 按下时回到原位。

### 3.6 页脚

- 顶部 1px 分隔线，左侧数据同步时间，右侧 Help/Feedback/Privacy 链接。

## 4. 体验约束（交互规则）

### 4.1 已实现的交互

- **hover**：指标单元、事件项、操作卡片和导航链接都有 `--surface-hover` 或加深背景。
- **focus-visible**：所有可交互元素显示 2px `--accent` 轮廓，偏移 2px。
- **active**：操作卡片按下时取消上浮，回到 `translateY(0)`；按钮缩小至 97%。
- **可点击性**：指标单元和事件项带有 `role="button"` 和 `tabindex="0"`，暗示可下钻。

### 4.2 状态反馈规则

- 正常指标：无边框，数字使用 `--text-primary`。
- 需关注：`--status-warn` 文字或边框，不闪烁、不弹窗。
- 错误：`--status-error` 文字或边框，同样克制。
- 所有状态过渡在 150ms 内完成，避免突兀。

### 4.3 尚未覆盖的状态

- 加载 / 骨架屏状态
- 空状态（无事件、未接入数据源）
- 错误状态（同步失败、数据缺失）
- 异常指标的下钻详情页

## 5. 动效与过渡

### 5.1 缓动曲线

全站唯一使用的缓动是 `cubic-bezier(0.25, 1, 0.5, 1)`（ease-out-strong），先快后慢、自然减速。

**禁用**：bounce、elastic、spring 等回弹曲线。

### 5.2 时长规范

| 场景 | 时长 | 缓动 | 属性 |
|------|------|------|------|
| 悬停反馈 | 150ms | ease-out-strong | background, transform, border-color |
| 按压反馈 | 150ms | ease-out-strong | transform: scale(0.97) |
| 箭头位移 | 200ms | ease-out-strong | transform: translateX(3px) |
| 入场动画 | 350–500ms | ease-out-strong | transform, opacity |
| 细线描绘 | 800ms | ease-out-strong | transform: scaleX / scaleY |

### 5.3 动效清单

- **规则线描绘**：页面加载后，细线依次描绘入场（横向 0.8s，纵向 0.8s，延迟 0.2s/0.45s/0.65s）。
- **悬停过渡**：背景、边框和颜色变化使用 150ms ease-out。
- **按压反馈**：按钮缩至 97%，卡片下沉 1px，干脆利落。
- **箭头反馈**：操作卡片悬停时箭头在 200ms 内右移 3px。
- **错峰入场**：多个元素入场时，以 50–100ms 的间隔错峰延迟。
- **减弱动效**：当 `prefers-reduced-motion: reduce` 生效时，所有动画时长强制为 0.01ms。

### 5.4 技术约束

- 只对 `transform` 和 `opacity` 做动画；避免布局属性（width、height、top、left）。
- 动效不能阻塞交互；动画进行中用户仍可操作。
- 所有动画时长控制在 500ms 以内，细线描绘是唯一例外（800ms）。

## 6. 红线

### 要做的

- 用细线构建结构与秩序。
- 让指标数字保持视觉主角地位，用 JetBrains Mono 强化。
- 用 `--status-ok` 表示"正常"，用 `--status-warn" 表示"需关注"，但避免大面积高饱和的警示色。
- 保留充足留白，让页面可以"呼吸"。
- 动效只用 ease-out-strong，保持干净的确认感。

### 不要做的

- 不用紫色、不用蓝色主色、不用渐变背景。
- 不在指标横栏内嵌趋势图或迷你图表（会制造信息焦虑）。
- 不把正常指标显示为红色/橙色。
- 不在卡片里嵌套卡片。
- 不用纯黑 #000000 或纯白 #FFFFFF。
- 不用 bounce / elastic 缓动曲线。
- 不用持续闪烁的警报。
- 不用超过 500ms 的入场动画。

## 7. 表面与层级

| 层级 | 用途 | 颜色 |
|-------|------|------|
| 0 | 页面画布 | `--bg-page` |
| 1 | 导航、卡片、操作项 | `--surface-card` |
| 2 | 悬停反馈 | `--surface-hover` |
| 3 | 强调区块 | `--badge-bg` |

层级策略：不用阴影做分层；层级只靠 1px 细线和背景色差建立；仅悬停时允许轻阴影。

---

## 8. 图像与布局

- 不使用插画、摄影图或 Logo 墙。
- 页面骨架：吸顶导航 → 报头 → 指标横栏 → 双栏布局（事件流 + 快捷操作） → 页脚。
- 栏宽比例：主栏 1fr，侧栏 360px。
- 视觉节奏：靠细线和分区间距建立，而不是卡片阴影。

---

## 9. 响应式行为

- **> 960px**：4 列指标横栏 + 双栏布局。
- **≤ 960px**：指标横栏变为 2×2 网格；主栏与侧栏堆叠为单栏；导航链接隐藏（可用汉堡菜单替代）。
- **≤ 560px**：指标横栏单列；事件项切换为 2 列网格，时间独占一行。
- 移动端内边距：20px。
- 触控目标：导航链接、操作卡片和事件项高度均 ≥ 44px。

---

## 10. 规范驱动约束

- 颜色、字体和圆角必须引用 CSS 变量；不允许硬编码数值。
- 新页面必须遵循 `--bg-page`、`--text-primary`、`--accent` 和细线的设计语言。
- 指标横栏、事件流和操作卡片应抽取为可复用组件。
- 技术栈绑定：暂无；目前是静态 HTML/CSS 原型。

## 11. Agent 提示词指南

### 快速色彩参考

- 背景：`#F5F4F0`
- 主要文字：`#1F1F1F`
- 点缀色：`#2D5A3D`
- 卡片：`#FAFAF8`
- 边框：`#DEDCD5`
- 警告：`#9A6B2B`
- 错误：`#8B3A2E`

### 示例提示词

- "使用 Pulse 设计系统生成一个数据详情页，保留细线和 Source Serif 4 标题，主色 `#2D5A3D`。"
- "为 Pulse 添加一个空状态组件，使用 `--surface-card` 背景、`--border-subtle` 虚线边框和 Manrope 13px 文案。"
- "为 Pulse 首页新增一种事件类型，保留事件流组件的 3 列网格和悬停背景变化。"

### 常见错误

- 误用蓝色作点缀 → 改为 `#2D5A3D`。
- 在指标横栏加 sparkline → 去掉，保持数字纯粹。
- 给卡片加重阴影 → 只允许悬停时的轻阴影。
- 使用 bounce 缓动 → 改为 `cubic-bezier(0.25, 1, 0.5, 1)`。
- 让警报闪烁 → 改用稳定的边框/文字高亮。
