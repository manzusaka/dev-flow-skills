# 参考收集 · Pulse

## 用户推荐

本案例中用户未提供竞品或其他参考产品。

## Agent 推荐

### 同类产品（清晰但不冰冷的数据仪表盘）
- **Stripe Dashboard**（dashboard.stripe.com）：收入数据可视化的标杆。研究金额、趋势和异常状态如何共处一屏。
- **Linear**（linear.app）：极客风 SaaS 后台的标杆；通过布局密度和留白兼顾速度与沉静。
- **Plausible Analytics**（plausible.io）：面向独立开发者的隐私友好型极简分析工具。看看"少即是多"如何发挥作用。
- **Fathom Analytics**（usefathom.com）：比 Plausible 更有温度；是"专业 + 不冰冷"配色的好参考。

### 跨品类氛围参考（沉静 + 速度的表达方式）
- **Notion**（notion.so）：生产力工具的沉静感；文本层级和卡片组织方式值得研究。
- **Kinfolk**（kinfolk.com）：杂志感、低饱和度、大量留白；是"沉静"视觉感受的来源。
- **Aesop**（aesop.com）：克制中带着温度；色彩有层次而不嘈杂。
- **Monocle**（monocle.com）：编辑感 + 信息密度；克制与可读性兼顾。最接近 Pulse 想要的"沉静中的秩序"。

### 设计灵感画廊
- **Mobbin**（mobbin.com）：真实应用/网页截图；搜索 "dashboard" / "analytics" 可以得到大量后台案例。
- **Awwwards**（awwwards.com）：网页设计奖项；搜索 "SaaS dashboard" 寻找视觉突破。
- **Godly**（godly.website）：精选的高完成度网站；适合把握整体氛围。

### 字体灵感
- **Typewolf**（typewolf.com）：真实场景的字体搭配；适合寻找 Display + Body 组合。
- **Fontshare**（fontshare.com）：可免费商用的字体，质量高，适合原型和生产环境。

## 用户笔记

### 参考 1：Notion
- **整体印象**：非常沉静；留白和文本层级很舒服。但担心对数据仪表盘来说过于空旷，密度可以再高一些。
- **可借鉴**：沉静感、文本层级、留白节奏。
- **需避免**：对数据仪表盘而言太空，密度不足。
- **可提取元素**：有层次的排版、克制的卡片间距。

### 参考 2：Kinfolk
- **整体印象**：喜欢低饱和度和大留白带来的沉静感，但杂志感对 SaaS 后台来说太强了。
- **可借鉴**：低饱和度、沉静感、大留白。
- **需避免**：过于编辑化的杂志感，不适合工具型后台。
- **可提取元素**：低饱和度的色彩用法、舒缓的页面节奏。

### 参考 3：Aesop
- **整体印象**：克制中的温度很棒；色彩有层次而不嘈杂。但高级感偏奢华，面向独立开发者的工具应该更亲和。
- **可借鉴**：克制中的温度、有层次的色彩、安静感。
- **需避免**：过于奢华/高级，与独立开发者有距离感。
- **可提取元素**：温暖而安静的色彩逻辑。

### 参考 4：Monocle
- **整体印象**：最喜欢。编辑感 + 信息密度的平衡很好；克制但可读。正是 Pulse 想要的"沉静中的秩序"。
- **可借鉴**：编辑感、信息密度、可读性、克制中的秩序。
- **需避免**：没有明显的负面点。
- **可提取元素**：密度与留白的平衡、编辑式排版、有序但不冰冷的阅读节奏。

## 提炼出的设计线索

- **整体情绪倾向**：沉静中的秩序、克制但可读、编辑感、亲和而不廉价、专业而不冰冷。
- **色彩倾向**：浅色模式；低饱和度、暖中性色打底；不要紫色、不要蓝色主色、不要渐变；可考虑暖灰、米白、柔和大地色，或用哑光绿/赭色作点缀。
- **字体倾向**：以清晰易读的无衬线字体打底；Display 可以带一点人文/编辑气息；强调层级而非装饰。
- **布局倾向**：比 Notion 更密，比密集型企业仪表盘更轻；卡片式组织；关键数字优先；留白有节奏但不空旷。
- **坚决不要**：默认深色主题、紫色主色、蓝色主色、渐变背景、过于杂志化、过于奢华。
